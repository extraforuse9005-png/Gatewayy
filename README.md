# FamePay Gateway

Run locally or on any host that supports Node.js 18+:

    npm install
    npm start

Then open http://localhost:3000

1. Integration: enter Gmail, Google app password, UPI ID, then Connect.
2. Test payment: enter an amount and tap Pay. A QR window opens. The page checks your inbox for 3 minutes.
3. API docs: copy the code for your framework.

Data is stored in data.json next to server.js.
